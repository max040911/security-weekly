## 短引述

> "XZ Utils 5.6.0 and 5.6.1 release tarballs contain a backdoor."

## 事實摘錄（依原頁）

- The 5.6.0 and 5.6.1 tarballs were created and signed by Jia Tan.
- Jia Tan's access was limited to GitHub-hosted items, including the xz.tukaani.org subdomain.
- 2024-03-30: xz@tukaani.org stopped forwarding to Jia Tan.
- 2024-04-09: the XZ Git repositories became available on GitHub again.
- 2024-05-29: review notes 1.0 published; new, clean XZ Utils releases were made.
- The malicious files stay in Git history; they are harmless without trigger code that was never in the Git repository.
