# 來源｜NVD 漏洞條目（4 筆）

- raw：[nvd-cves](../raw/nvd-cves.md)（由 NVD API 取得）
- 原始網址：<https://nvd.nist.gov/>
- 發布者：美國 NIST 國家漏洞資料庫
- 授權：美國政府著作（公有領域）

## 重點摘要

1. **CVE-2024-3094**（xz）：2024-03-29 發布，CVSS 10.0。惡意程式碼在 xz 的上游 tarball 中，從 5.6.0 版開始。
2. CVE-2024-3094 機制：liblzma 的建置過程從一個**偽裝成測試檔**的檔案中取出預先編好的目的檔，用來修改 liblzma 的特定函式；任何連結這個函式庫的軟體都可能被攔截。
3. **CVE-2021-44228**（Log4Shell）：2021-12-10 發布，CVSS 10.0。Log4j2 2.0-beta9 起的 JNDI 功能沒有防範攻擊者控制的 LDAP 端點。
4. CVE-2021-44228：從 2.15.0 起此行為預設關閉；2.16.0 起完全移除。
5. **CVE-2021-45046**：2.15.0 修補不完整的後續漏洞。
6. **CVE-2021-44832**：2021-12-28 發布。2.0-beta7 through 2.17.0 受影響，修補於 2.17.1、2.12.4、2.3.2。

## 與其他來源的衝突

- CVE-2021-44832 修補版本與 [Apache 安全公告](apache-log4j-security.md) 不一致，詳見該頁；本 Wiki 採用本來源。
